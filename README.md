## Image Deduplicator

Given a set of images, aims to find duplicates (using difference hashing) and delete duplicate instances detected.

## Requirements
To run this program, you will need to have Python installed on the machine.

Additionally, you will also need to have all the packages listed in `requirements.txt` installed.

To install them, clone this repo run the following command in the terminal from the folder:

```python
pip install -r requirements.txt
```
